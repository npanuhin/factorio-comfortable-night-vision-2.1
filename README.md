<h1 align="center">Comfortable Night Vision 2.1</h1>

When using the nightvision equipment, the color tone will stay **the same as at sunset** instead of changing into the hard on the eye desaturated one.

Port of the original [Comfortable Night Vision](https://mods.factorio.com/mod/comfortable-night-vision) mod by [plexpt](https://mods.factorio.com/user/plexpt).
